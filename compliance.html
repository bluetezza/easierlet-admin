Compliance rule library

The master list of UK landlord compliance requirements. Edits propagate to every property in the matching jurisdiction. Adding a new rule backfills property_compliance rows for matching properties as pending.
How edits propagate
  • Add a rule — every property in the matching jurisdiction immediately gets a pending row.
  • Update a rule — affects how the rule is presented; existing per-property records (last completed / next due / certificates) are untouched.
  • Delete a rule — only allowed if no property has a certificate filed under it. To "retire" a rule with history, leave it in place and remove it from applies_to via the editor (handled automatically by the trigger).
  • Frequency change — the next time a landlord marks a requirement complete, the new frequency is used to compute the next due date.
